# Student Management System

A console-based **Student Management System** built using C++. This project focuses on practicing structured programming, data management, input validation, functions, pointers, and working with student records.

<sub>🚧 **PROJECT STATUS: IN DEVELOPMENT — NOT YET COMPLETE**</sub>

---

## Features

### Implemented

- **Register Students** — Add new student records.
- **Search Students** — Search for a student using their ID.
- **Input Validation** — Validate student IDs, names, age, course, and marks.
- **Average Marks** — Calculate the average marks of registered students.
- **Highest Marks** — Find the student with the highest marks.
- **View Student Records** — Display all registered student data.
- **Menu System** — Navigate through the available operations.

### Upcoming

- **Update Student Marks** — Modify the marks of an existing student.
- **Delete Student Records** — Remove a student using their ID.
- **Improved Input Handling** — Strengthen input validation and error handling.
- **Data Persistence** — Save student records to files and load them when the program starts.
